# 🎭 لعبة المافيا الذكية

نسخة متطورة ومؤتمتة من لعبة المافيا/الذئب تعمل **بدون مشرف بشري**.

---

## 📁 هيكل الملفات

```
mafia-game/
├── server.js      ← عقل اللعبة (Node.js + Socket.io + NFC)
├── index.html     ← واجهة اللعب للهواتف
├── style.css      ← التصميم (Dark Theme, Mobile-First)
├── app.js         ← ربط الواجهة بالسيرفر (Real-time)
└── package.json   ← المكتبات المطلوبة
```

---

## 🚀 تشغيل اللعبة

### المتطلبات
- Node.js الإصدار 16 أو أحدث
- npm

### الخطوات

```bash
cd mafia-game
npm install
node server.js
```

السيرفر يعمل على: **http://localhost:3000**

---

## 📱 طريقة اللعب

### للاعبين
1. فتح **نفس الشبكة** (WiFi المنزل مثلاً)
2. الدخول لـ `http://[IP-السيرفر]:3000`
3. إدخال الاسم والضغط على "أدخل اللعبة"

### لبطاقات NFC (اختياري)
- برمج بطاقات NFC بروابط مثل: `http://[IP]:3000/scan/card1` إلى `card10`
- بمجرد المسح، يُحوَّل اللاعب تلقائياً لـ `/play` وتُقفَل البطاقة

---

## 🔐 لوحة التحكم السرية (Admin)

**كيفية الدخول:** اضغط 5 ضغطات متتالية على عنوان "لعبة المافيا" في الأعلى

**الرمز السري:** `901332`

**الصلاحيات:**
- ▶️ **بدء اللعبة** — يوزع الأدوار ويبدأ أول ليلة
- 🗳️ **فتح التصويت** — بعد النقاش النهاري
- 🚫 **طرد لاعب** — لمن علق قبل الاستعداد
- 🔄 **إعادة تشغيل** — تصفير كامل وفتح بطاقات NFC

## 🌙 دورة اللعبة

```
ليل (35 ثانية)
  ↓ المافيا تصوت على ضحية سراً
  ↓ الطبيب يختار من يحمي
  ↓ المحقق يكشف هوية لاعب
  ↓ المواطنون يضغطون أزرار التشتيت
نهار → إعلان الضحية → نقاش
  ↓ المالك يفتح التصويت
  ↓ كل لاعب يصوت على من يعدمه
  ↓ تعادل؟ → جولة حاسمة 40 ثانية
ليل → ...
```

## 🛡️ نظام الحماية

- **Zero-Knowledge Client**: هاتف كل لاعب لا يعلم إلا دوره فقط
- **NFC Lock**: كل بطاقة تُقفل بعد الاستخدام
- **Flash Alert**: محاولة الغش تُظهر تنبيه أحمر وميضاً
- **DevTools Block**: تعطيل F12 وزر الماوس الأيمن

---

## 🏆 شروط الفوز

- **المواطنون**: موت آخر مافيا
- **المافيا**: عددهم ≥ عدد البقية (إذا لم يكن الجوكر حياً)
- **الجوكر**: أن يُعدَم بالتصويت النهاري

## 🔧 إعدادات الشبكة

للعب على شبكة محلية:
```bash
# اعرف IP جهازك
ipconfig  # Windows
ifconfig  # Mac/Linux

# اللاعبون يدخلون:
http://192.168.x.x:3000
```

للنشر عبر الإنترنت: استخدم **ngrok** أو **Railway** أو **Render**

```bash
# ngrok (الأسهل للتجربة السريعة)
ngrok http 3000
```
